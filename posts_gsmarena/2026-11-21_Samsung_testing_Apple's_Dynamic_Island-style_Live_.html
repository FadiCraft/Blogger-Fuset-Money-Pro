Samsung introduced Live Notifications with One UI 7 and is now working on a visual change that would make the feature feel more like Apple's Dynamic Island.

Right now, Live Notifications appear as a compact pill in the top-left corner of the status bar, showing key information such as a timer or a recording indicator. If it shows information from different apps, you can switch between them by swiping up or down on the pill.

The redesigned Live Notifications Samsung is working on appear in the center and replace vertical swipes with horizontal swipes, so instead of swiping up or down, you swipe left or right to switch between activities without expanding the pill first. You can see the clip below showing the new Live Notifications in action.

If Samsung finalizes this version of Live Notifications and rolls it out to users, it won't be the first Android brand to offer a feature similar to Apple's Dynamic Island, since we've already seen similar stuff from some Chinese brands.

Redesigned Live Notifications

Samsung is testing the new Live Notifications in One UI 9.5, which is currently only available to the Galaxy S26 series through the beta program in select countries. We could see Live Notifications debut with the Galaxy S27 series, which is expected to ship with stable One UI 9.5.
