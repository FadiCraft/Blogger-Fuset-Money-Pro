About a couple of weeks after Samsung released the fifth beta of One UI 9 for the Galaxy S26 series, today the company is rolling out the sixth beta build. It's an 851MB update and includes the August 5, 2026 security patches. It's currently available in Germany, India, Poland, the UK, and Korea and should be making its way to the US soon.

If you are part of the beta program, once you've installed the sixth beta, your phone will be running build ZZHE. It includes fixes for display errors with the Now Brief widget and the home screen, photo-saving issues in Expert RAW 24MP at some focal lengths, and an issue with the camera widget.


Samsung One UI 9 beta 6 downloading (left), new Edge panel option (right)

It also brings a new "Touch and hold for AI select" toggle in Settings > Display > Edge panels. If you enable it, long-pressing the Edge panel peek window will trigger the AI select feature. If you disable it, long-pressing the Edge panel peek window will do nothing, helping you avoid possible accidental AI Select triggers. If you go this route you can continue to set AI Select as a shortcut in the Edge panel and use it from there.

AI Select is Samsung's new implementation of the Smart Select tool. It lets you select any portion of the screen to extract editable text, create animated GIFs from playing videos, or take images straight into Generative Edit and Drawing Assist. If you think of it as Samsung's version of Google's Circle to Search, you're not far off.
