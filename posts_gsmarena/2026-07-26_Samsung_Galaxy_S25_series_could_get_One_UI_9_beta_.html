Samsung is internally testing Android 17-based One UI 9 for several Galaxy devices, including the Galaxy S25 series; however, the Korean company has released One UI 9 beta only for the Galaxy S26 lineup so far. Well, the good news is the Galaxy S25 series could receive One UI 9 beta soon.

The first One UI 9 beta build for the Galaxy S25 Ultra has been spotted on Samsung's server with firmware versions S938NKSUBZZG8/S938NOKRBZZG8/S938NKSUBDZG8. However, note that the build is for the S25 Ultra's Korean model, so expect the One UI 9 beta to release in South Korea first, then expand to other markets later.

Samsung Galaxy S25 Ultra

Circling back to the Galaxy S26 series, Samsung hasn't revealed the rollout date for the stable One UI 9 for the S26 lineup, which makes the recently unveiled Galaxy Z Fold8 series and Flip8 the only smartphones to run the stable version of One UI 9.
