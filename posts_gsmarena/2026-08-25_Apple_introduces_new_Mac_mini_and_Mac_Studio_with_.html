Apple has updated its desktop Mac lineup with new range of processors for 2026. The Mac mini and the Mac Studio feature the latest generation of Apple's M-series chips, making them the most powerful computers in the company's lineup.

The updated Mac mini now comes with the latest generation M6 chip. Based on the 2nm process, the M6 has a new 12-core CPU design along with a new 12-core GPU and dual 16-core NPU. Apple claims the new CPU has the fastest single-core performance in the world. The new GPU with built-in neural accelerators is 2x faster for graphics and 4x faster for AI workloads than the M4. The new NPU has 2x greater performance than before.

The M6 model starts with 16GB of unified memory, and can be configured up to 32GB. It also starts with 256GB of storage, and can be configured up to 2TB.

Apple is also offering the Mac mini with an M5 Pro option. This model features a 15-core CPU and a 12-core GPU, along with a single 16-core NPU. This model comes with 24GB of memory as standard, and can be configured up to 64GB. It also includes 512GB storage that can be taken up to 8TB.

Aside from the new chips, the new Mac mini also includes Wi-Fi 7, Bluetooth 6, as well as upgraded 2.5Gb Ethernet, with a 10Gb option available. Aside from that, the model is unchanged from the previous generation. The new Mac mini starts at $899 for the M6 model and $1699 for the M5 Pro model.

Moving on to the Mac Studio, the update model gets the M5 Max that we first saw on the MacBook Pro, as well as a new flagship M5 Ultra chip.

The M5 Max chip is unchanged from before. You can pick for the standard 18-core CPU and 32-core GPU layout, or opt for the 18-core CPU and 40-core GPU option in the configurator. You have 32GB of unified memory as standard, but it can be configured up to 64GB for the 32-core GPU chip or 128GB for the 40-core GPU chip. It comes with 512GB of storage as standard, and it can be configured up to 8TB.

Then there is the flagship M5 Ultra chip, the most powerful processor Apple currently makes. It features two dual M5 Ultra dies to create the quad-die monstrosity. They are connected together with Apple's UltraFusion interconnect with 4.4TB/s of bandwidth. By default, you get a 30-core CPU and 64-core GPU, but you can also opt for a 36-core CPU and 80-core GPU model. Memory stars at 96GB and goes up 512GB for the 80-core GPU model. You also get 1TB storage as standard, which can be taken up to 16TB.

Like the Mac mini, the Mac Studio also gets Wi-Fi 7 and Bluetooth 6, along with six Thunderbolt 5 ports. The Mac Studio starts at $2499 for the M5 Max model and $5499 for M5 Ultra model. And since everyone is wondering how much expensive it can get fully maxed out, the answer currently is $18,299, and that's only because you can only get up to 256GB memory right now, as the 512GB option is arriving in late October.
